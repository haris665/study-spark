# Study Spark on Replit

## Run the app

- Use the **Start application** workflow in Replit.
- The workflow runs `npm run dev`.
- The Vite development server listens on `0.0.0.0:5000` for Replit's web preview.

## Optional integrations

The core app can start without external credentials. AI question generation and reminder emails require the corresponding environment variables listed in `.env.example`. Store credentials in Replit Secrets rather than committing them to files.

## Project compatibility

This project remains connected to Lovable. Preserve the existing TanStack Start/Vite structure and avoid rewriting published Git history.
